stone-engine.js オートモード（試作）

読み込むだけで、文字組みを整える

このページは普通の HTML です。スクリプトを 1 行読み込んで、記事に data-stone 属性を付けただけで、 段落と見出しが日本語組版エンジンで組み直されています。上の「組む」を切り替えると、 ブラウザの普通の表示と見比べられます。

約物が続くところ

括弧や句読点が続くと、普通の表示では間が空いて見えます。たとえば「これは『入れ子』の括弧です。」（補足も続きます）、 という文です。組むと、約物どうしの間が詰まり、行頭の「始め括弧」も行の頭にそろいます。

リンクや強調もそのまま

段落の中のリンクは、そのままクリックできます。 太字や斜体、文字色、下線、打ち消し線も、CSS で決まった見た目のまま組まれます。ページ内の縦書きの節へのリンクも動きます。

行末をそろえる

text-align: justify を指定した段落は、行末がそろうように文字の間を均等に広げます。English words や 2026 のような数字が混ざっても、単語の途中は広げません。行頭に句読点や「ー」が来ないように、禁則処理も行います。HTML のソースを途中で改行していても、和文の間に余計な空白は入りません。

フレックスの子のように、幅が内容で決まる要素でも、テキストのときと同じ幅になります。

組まないもの

エンジンがまだ再現できないものを含む段落は、何もせずに元の表示のまま残します。「組んだ場所を表示」で理由が見られます。

振ふり仮名がな（ルビ）のある段落は、読みが落ちてしまうので組みません。

code のように、フォントや大きさの違う文字がある段落も組みません。

字間（letter-spacing）を空けた段落も、今は組みません。

  • 箇条書きの項目（li）には Shadow DOM を付けられないので、対象にしていません。

フロートが回り込んでいる段落も組みません。回り込みに合わせて行の長さを変える組み方に、エンジンが対応していないためです。 この段落は左の四角を避けて折り返しています。

縦書き

writing-mode: vertical-rl の中の段落は、縦書きで組まれます。句読点や括弧「」は縦組みの字形になり、 2026年11月のような数字は、2桁までなら縦中横になります。

English のような欧文は、90度回転して組まれます。高さに合わせて折り返し、左へ行が増えていきます。

後から増える段落

上の「段落を追加」を押すと、ここに段落が増えます。追加された段落も、自動で組まれます。
